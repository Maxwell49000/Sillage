# Interface Sillage

Application Vue 3 de l’assistant documentaire Sillage.

```powershell
npm install
npm run dev
```

Le serveur de développement écoute sur `http://localhost:8000` et relaie `/api` vers le backend Spring Boot. Les instructions complètes, l’architecture et les variables d’environnement sont décrites dans le [README principal](../README.md).

## Commandes

- `npm run dev` : serveur de développement ;
- `npm run lint` : analyse statique des fichiers Vue et JavaScript ;
- `npm run build` : bundle de production dans `dist/` ;
- `npm run preview` : prévisualisation du bundle.
